# Website cửa hàng văn phòng phẩm

Dự án **quản lý dữ liệu bán hàng** và *theo dõi log* cho cửa hàng văn phòng phẩm.

| Thư mục | Nội dung |
| --- | --- |
| `docs` | Ghi chú nhập hàng trong `nhap_hang.txt` |
| `media` | Logo của cửa hàng |
| `data` | Bảng tính đơn bán tháng 10 |
| `logs` | Log gốc và các báo cáo lỗi, tổng hợp |
| `backup` | Bản sao logo dự phòng |

Liệt kê toàn bộ nội dung dự án, kể cả file ẩn:

```bash
ls -aR
```

- [x] Sắp xếp file và thư mục dự án.
- [x] Tạo báo cáo lỗi và báo cáo tổng hợp.
- [ ] Kiểm tra bảng tính và hoàn tất nộp bài trên GitHub.

> Không upload file `.env` lên GitHub.
